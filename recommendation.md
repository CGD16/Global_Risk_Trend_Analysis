### 🛠️ Open-Source Selfhosted Web Search Tools

- [SearXNG](https://github.com/searxng/searxng) – Self-hosted metasearch engine
- [Firecrawl](https://github.com/firecrawl/firecrawl) - Self-hosted web scraper for ai

- uv – Fast Python package and project manager with virtual environment management, dependency resolution, and reproducible installations using uv.lock.

- FastAPI – Python API framework providing REST endpoints, automatic OpenAPI documentation, and an interface for orchestrating research agents.
